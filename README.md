# Sistema de Registro de Calificaciones

## Descripción
Programa desarrollado en Python para el registro de estudiantes, calculo de promedios de tres calificaciones y determinacion de su estado academico

## Autor
* Emilio Walter Garcia Burgoa
* Asignatura: Programación Fundamental (PFU-111)

## Funcionalidades y Validaciones
* Registro iterativo de estudiantes.
* Validación estricta de nombres no vacíos.
* Control de rango numérico en notas (0 a 100).
* Manejo de excepciones (`ValueError`) ante entradas de texto no válidas.
